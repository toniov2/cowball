# Cowball v46.4 — UI/карьера

## Выбор лиг и команд

- В обычном выборе команды по умолчанию открывается список клубных лиг: Премьер-лига, Ла Лига, Бундеслига, Серия A и Лига 1.
- Каждая карточка показывает страну, число клубов, среднюю силу в игровых данных и примеры команд.
- После выбора лиги список ограничивается командами этой лиги. Заголовок и кнопка «Все лиги» помогают понять текущее положение.
- Перед выбором команды кнопка продолжения отключена. Это предотвращает запуск матча со старым выбором, когда пользователь ещё не открыл лигу.
- После выбора своей команды список лиг сбрасывается, чтобы соперника можно было выбрать из другой лиги. Вкладки «Выдуманные команды», «Сборные» и «Все» остаются доступны.
- Турниры, где лига уже выбрана отдельным экраном, сохраняют прежний поток выбора команды.

## Визуальная часть

- Добавлен дополнительный тонкий пульсирующий ореол вокруг существующего индикатора активного игрока; исходное кольцо и стрелка продолжают управляться игровым движком.
- Плашка активного игрока получила более контрастный вид и читаемое обозначение.
- Открытие карточек получило дополнительные эффекты глубины и импульса; существующая логика получения и сохранения карточек не менялась.

## Карьера

- В обзоре активной карьеры показаны матчи, победы, ничьи, забитые/пропущенные голы и очки текущего сезона.
- Статистика берётся из уже существующих полей сохранения; формат и значения сохранений не мигрируются и не сбрасываются.

## Файлы

- `cowball-v47-ui.js` — отдельный интерфейсный модуль для выбора лиг, ореола игрока и отображения статистики карьеры.
- `cowball-v47-ui.css` — стили карточек лиг, индикатора активного игрока, карьеры и открытия карточек.
- `index.html` — подключение новых CSS/JS модулей.
- `cowball-core.js` — выбор клубной лиги по умолчанию, сброс выбора лиги при переходе к выбору соперника, версия приложения `1.9.2`.

## Проверки и ограничения

- `node --check` пройден для всех JavaScript-файлов.
- Проверены локальные `src` и `href` в `index.html`; отсутствующие файлы не обнаружены.
- Изолированный smoke-тест подтвердил: вывод пяти лиг, фильтрацию команд по выбранной лиге, защиту от продолжения без выбора лиги, добавление сводки карьеры и монтаж дополнительного ореола игрока.
- Полноценный интерактивный запуск матча в браузере в этой среде не подтверждён. Перед публикацией рекомендуется проверить новый поток выбора на телефоне и компьютере.
