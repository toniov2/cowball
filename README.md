# Cowball v50 (Phase 0) — GitHub Pages

> v51: каркас Vite + TypeScript, см. PHASE1_V51.md

`index.html` — точка входа. Все игровые файлы находятся в корне проекта, без обязательной сборки; проект рассчитан на размещение на GitHub Pages.

**Аудио и геймплей:** восстановлен `pasture.mp3`, убрана только плашка текущего трека, сохранены песни и звуковые настройки; добавлены плавные переходы музыки. Улучшены инерция движения, выбор коридора для дриблинга, оценка перехвата мяча, дуга заряженного удара, коллизия перекладины и профили запасных. Физика, ИИ и номера вынесены в лёгкие отдельные модули.

**Интерфейс v47 UI:** выбор клубов начинается с отдельного экрана лиг и затем открывает команды выбранной лиги; повторный выбор лиги доступен для соперника. Улучшена отметка управляемого игрока, в обзоре карьеры показана статистика сезона, а анимация карточек получила дополнительные эффекты.

Three.js r128 загружается с CDN (для первого запуска нужен интернет); при желании положите `three.min.js` рядом с `index.html`.

Поддерживаются матчи, турниры, карьера, Ultimate Team и локальные сохранения (`localStorage`). P2P использует WebRTC. Функции облачного профиля, рейтинга и глобальных турниров требуют отдельного сервера; см. `server.js` и `server_README.md`.

Проверки этой сборки: синтаксис JavaScript, локальные пути HTML и отдельный smoke-тест переходов UI. Полный интерактивный браузерный тест матча в этой среде не подтверждён.

### Фаза 2 (v52): рендер толпы
- Старые зрители-Group (≈300 мешей, ~600 draw call + цикл на CPU каждый кадр) убраны; вся толпа в 5 InstancedMesh.
- Толпа развёрнута лицом к полю на всех 4 трибунах, головы следят за мячом, болельщики забившей команды прыгают, остальные опускают головы.
- frustumCulled=false для инстансов (иначе толпа могла пропадать при повороте камеры).
- Не проверено на настоящем Three.js: в песочнице его нет, проверена только математика поз и загрузка страницы.
- Ступени и сиденья трибун слиты в 2 меша на трибуну (было по 2 на каждый ряд, ~70 draw call); при ошибке слияния включается прежний путь.
