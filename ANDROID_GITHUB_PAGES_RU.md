# Как опубликовать с Android (Brave)
1. Распакуйте Cowball_v46_GitHubPages.zip (Files / ZArchiver).
2. github.com → New repository → имя, например `cowball`, Public → Create.
3. Add file → Upload files → выберите ВСЕ распакованные файлы сразу (без папок) → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
5. Через 1–2 минуты игра откроется: https://ИМЯ.github.io/cowball/
Лимит веб-загрузки GitHub — 100 файлов за раз (здесь около 40) и до 25 МБ на файл.
