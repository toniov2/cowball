# Cowball model assets

The cow players, ball panels, goals, tunnel and stadium geometry are currently generated procedurally by `cowball-core.js` with Three.js. This keeps the animated rigs compatible with the original gameplay and avoids adding a large imported-model dependency. Version v44 adds separate woven-kit, ball-pebble, stadium-seat and concrete textures to those existing models. This folder is reserved for future optional GLB/glTF models; no unused dummy model files are shipped.
