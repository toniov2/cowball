## НЕ сделано / НЕ проверено (честно)
- **3D**: настоящего `three.min.js` нет, тесты идут на заглушке. Положи файл рядом с `index.html` (или `node tools_fetch_three.js`) и перезапусти `npm test`. Без него пункт 5 из брифа (локальная копия, SRI) закрыт только инструментом, не результатом.
- **Звук на слух и 3D на глаз** не проверялись. Свистки проверены по таймерам, не по звуку.
- **Пункт 13 (WebAudio-буферы)** перенесён в Фазу 6: без прослушивания менять звуковой движок рискованно.
- **Пункт 14**: слои обёрток (`Audio_.crowd` ×3, один файл 889 КБ) НЕ разбирались. Это задача Фазы 1 (модули + автомат состояний), удаление слоёв вслепую может сломать звук.
- **Пункт 20, остаток**: ~110 вызовов `Math.random()` в геймплее и визуале остались. Геймплейная детерминированность придёт с фиксированным шагом физики в Фазе 1.
- **Пункт 19**: статический аудит, профилирования памяти не было.
- Тест 13 («div получили role») пока не доказывает ничего, если таких элементов нет на стартовом экране; тест 12 проверяет только видимые на старте кнопки.
- Онлайн-режим (WebRTC/WebSocket) целиком не запускался; `server.js` проверен только по CORS и `/health`, с заглушкой `ws`.
