# Cowball v46.3 / gameplay helpers v47

## Изменения второго этапа

- `cowball-physics.js`: общая модель ускорения, торможения и инерции поворота; функция для дуги заряженного удара; проверки высоты мяча относительно перекладины.
- `cowball-ai.js`: оценка нескольких коридоров ведения мяча с учётом соперников, свободного пространства и границ поля. Проверен сценарий, в котором защитник перекрывает прямую линию движения.
- `cowball-rosters.js`: исправление известных игровых номеров с контекстными исключениями для некоторых клубов и сборных. Вызов идёт через данные текущей команды.
- `cowball-core.js`: оценка времени перехвата свободного мяча с небольшим удержанием текущего пресингующего, плавное движение игроков, дуга удара, коллизия перекладины и улучшенные резервные профили с разными атрибутами.
- `index.html`: лёгкие модули подключены до основного движка, без сборщика и без изменения способа запуска на GitHub Pages.

## Проверка и ограничения

- JavaScript прошёл синтаксическую проверку.
- Вспомогательные функции протестированы отдельно в Node.js, включая выбор обходного коридора при блокирующем защитнике и номер Криштиану Роналду №7.
- Проверены локальные `src`/`href` из `index.html`; отсутствующих локальных ссылок не найдено.
- В этой среде нет установленного браузерного раннера, поэтому полноценный визуальный матч-тест не выполнялся.
- Текущие списки футболистов, уже встроенные в проект, не проходили онлайн-верификацию на сезон 2026/27. Не считать весь состав каждой команды подтверждённо актуальным. Номера также зависят от команды/сборной; таблица исправляет выбранные известные случаи, а не заменяет официальную базу всех игроков.
